How it works

  1. Every generate interval, a new fish is procedurally generated (ported from fishdraw) along with a scientific-sounding binomial name.
  2. It's laid out as one of three textbook designs. Textbook page is portrait, with a figure, caption, classification line and an invented species description written by the on-board LLM, typed out word by word. Labelled figure and specimen plate are landscape and need no LLM. Page furniture — headings, captions, the name and date — is drawn first so it stays readable while the fish is still appearing.
  3. The panel is cleared with a single full refresh, then the fish is drawn on stroke by stroke across the draw duration using fast partial refreshes, so it builds up without the screen flashing again. The name and discovery date/time land with the last few strokes.
  4. By default draw progressively is off, so each finished page appears in a single refresh every 120 s. Turn it on to watch the page being drawn — but a partial refresh costs about 0.6 s, so a smooth reveal needs a draw duration of minutes, and the period has to grow to fit it.
  5. This page mirrors the same image the panel shows — check it here if you don't have the board in view.
